## 阴影

深色在前，浅色在后。

| 层级 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| 卡片 | `0 4px 24px rgba(0, 0, 0, 0.30)` | `0 4px 24px rgba(14, 14, 17, 0.06)` | 静态卡片 |
| 1 | `0 1px 2px rgba(0, 0, 0, 0.40)` | `0 1px 2px rgba(14, 14, 17, 0.06)` | 输入框、小按钮 |
| 2 | `0 4px 12px rgba(0, 0, 0, 0.35)` | `0 4px 12px rgba(14, 14, 17, 0.07)` | 轻微抬起 |
| 3 | `0 12px 32px -8px rgba(0, 0, 0, 0.55)` | `0 12px 32px -8px rgba(14, 14, 17, 0.14)` | 悬停、下拉 |
| 4 | `0 24px 64px -12px rgba(0, 0, 0, 0.70)` | `0 24px 64px -12px rgba(14, 14, 17, 0.22)` | 弹窗、浮层 |
| 光晕 | `0 8px 28px -6px rgba(130, 97, 255, 0.55)` | `0 8px 28px -6px rgba(118, 80, 255, 0.45)` | 主按钮悬停 |
| 聚焦 | `0 0 0 4px rgba(130, 97, 255, 0.22), 0 10px 32px -6px rgba(0, 0, 0, 0.55)` | `0 0 0 4px rgba(118, 80, 255, 0.18), 0 10px 28px -6px rgba(14, 14, 17, 0.14)` | 键盘聚焦 |

危险按钮悬停光晕：`0 8px 24px -6px rgba(255, 77, 94, 0.55)`。

## 间距

允许的间距：2、4、8、12、16、20、24、32、40、48、64、80。

| 场景 | 值 |
|---|---|
| 组件内部 | 8、12、16 |
| 表单项之间 | 12 |
| 栅格槽宽、行距 | 16 |
| 页边距 | 24；流式宽屏可增至 120 |
| 大卡片内边距 | 32 |
| 区块之间 | 32–80 |

## 渐变

不要自造新的渐变。品牌主渐变只用于会员、主推和 Hero。

| 名称 | 值 | 用途 |
|---|---|---|
| 品牌 | `linear-gradient(135deg, #8261FF 0%, #3D7BFF 100%)` | 会员、主推、Hero |
| 按钮 | `linear-gradient(180deg, #9479FF 0%, #7650FF 100%)` | 主按钮立体填充 |
| 会员 | `linear-gradient(90deg, #FF5FA2 0%, #8261FF 50%, #3D7BFF 100%)` | 全站会员、文字渐变 |
| 促销 | `linear-gradient(120deg, #FFB547 0%, #FF5FA2 100%)` | 促销横幅、折扣 |
| 新品 | `linear-gradient(135deg, #2FC77E 0%, #3D7BFF 100%)` | 免费、新品 |
| Hero 光晕 | `radial-gradient(60% 80% at 50% 0%, rgba(130, 97, 255, 0.45) 0%, rgba(10, 10, 15, 0) 70%), #0A0A0F` | 首页顶部光晕 |
| 表面过渡 | `linear-gradient(180deg, #1A1A28 0%, #0A0A0F 100%)` | 卡片底部遮罩 |
| 玻璃高光 | `linear-gradient(135deg, rgba(255, 255, 255, 0.16) 0%, rgba(255, 255, 255, 0.02) 100%)` | 玻璃边缘高光 |

浅色下 Hero 光晕透明度减半，且光斑不漂移。

## 动效

缓出：`cubic-bezier(0.25, 0.8, 0.25, 1)`。回弹：`cubic-bezier(0.34, 1.56, 0.64, 1)`。往返：`cubic-bezier(0.45, 0, 0.55, 1)`。

| 名称 | 时长 | 曲线 | 用途 |
|---|---|---|---|
| 快 | 150ms | 缓出 | 颜色、透明度、图标 |
| 基础 | 200ms | 缓出 | 按钮、输入框、悬停 |
| 中 | 300ms | 缓出 | 卡片抬升、下拉 |
| 回弹 | 400ms | 回弹 | 点赞、开关 |
| 页面 | 320ms | 缓出 | 视图进入：上移 8px 后淡入 |
| 通知进入 | 240ms | 缓出 | 提示自上淡入 |
| 滑入 | 320ms | 缓出 | 自右移入 24px |

## 图标线宽

尺寸只取 16、20、24、32、40、48、64。

| 尺寸 | 线宽 |
|---|---|
| < 24 | 0.75px |
| 24–31 | 1px |
| 32–39 | 1.75px |
| 40–60 | 2px |
| > 60 | `2px × 尺寸 / 60` |

## 栅格

| 参数 | 值 |
|---|---|
| 列数 | 24 |
| 槽宽 | 16 |
| 导航展开 / 折叠 | 240 / 64 |
| 页边距 | 24，流式宽屏上限 120 |
| 限宽内容 | 1680，视口 > 1920 时居中 |
| 最小页面宽度 | 1280 |
| 紧凑密度 | 可用内容宽度 < 1300 |

跨 n 列的宽度 = `n × 列宽 + (n − 1) × 16`。

## 图表色

按顺序使用，不要替换：`#8261FF`、`#3D7BFF`、`#22C3A6`、`#FF8A3D`、`#FF5FA2`、`#FFB547`。

K 线：涨用危险色，跌用成功色。

## 反馈

| 种类 | 位置与时间 |
|---|---|
| 提示 | 距顶 24，同时最多 3 条，2400ms |
| 通知 | 右上边距 24，宽 360，同时最多 4 条，4500ms，悬停暂停 |
| 活动卡 | 宽 320，右下角 |
