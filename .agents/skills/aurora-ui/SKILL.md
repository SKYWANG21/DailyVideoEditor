# Aurora 视觉规范

只约束界面看起来怎样。用当前项目已有的样式手段实现，不要求特定框架、组件库或文件结构。数值以 [tokens.md](tokens.md) 为准；做界面前先读该文件。不要另造颜色、字号、圆角、阴影或渐变。

深色为默认。浅色必须使用成对的浅色值，两套同时成立。

## 层级

页面由底到面逐级抬高，不要靠外框描边区分卡片和面板。

1. 页面底
2. 表面：面板、卡片
3. 表面-2：卡内区块、悬停
4. 表面-3：控件、浮层

分割线只用于表格、长列表等内容密集处。控件描边用「控件线」，比分割线更明确。面板和卡片不加外框线。

强调色是唯一品牌色，用于主按钮、选中和链接。每屏只有一个主按钮。危险色只用于破坏性操作和错误。成功、警告、危险不要拿来做装饰。

品牌渐变（135° 紫→蓝）只用于会员、主推和 Hero。其余渐变只按 tokens.md 里写明的用途使用。

界面里不使用 emoji。

## 排版与间距

正文用思源黑体，默认 14px / 字重 500 / 行高 1.5。标题用负字距。需要凸显的数字用数字字体，并使用等宽数字。代码用等宽字体。字号只取字阶表里的尺寸，紧凑布局时也不缩小字号。

间距以 4px 为基数。组件内部用 8、12、16；区块之间用 32–80。表单项上下间距 12。带框表单的标签和值用 14px；标签在上方或浮动时，标签用 12px。

## 圆角、阴影、动效

圆角按对象选取：标签 4，控件 8，卡内块 12，面板和卡片 16，Hero 20，胶囊用全圆。

静态卡片可以没有阴影，或只用卡片阴影。输入和小按钮用 1 级，静态抬起用 2 级，悬停和下拉用 3 级，弹窗和浮层用 4 级。主按钮悬停用强调色光晕。聚焦环为 4px 柔光。

过渡使用统一的缓出曲线。颜色和图标 150ms，控件悬停 200ms，卡片抬升和下拉 300ms，微交互回弹 400ms。页面进入为上移 8px 后淡入，约 320ms。系统开启「减少动效」时取消这些动画。

滚动条默认隐藏，滚动仍然可用。需要可见滚动条时，仅在指针悬停时显示 8px 胶囊滑块。

## 布局

应用内容区为 24 列，槽宽 16，列间距等于行间距。左侧导航展开 240、折叠 64。页边距在视口 ≤ 1920 时为 24。

| 视口宽度 | 导航 |
|---|---|
| > 1920 | 展开 240。流式页面随宽度变宽，页边距按 `min(24 + (宽度 − 1920) × 0.1, 120)` 增加；表单、详情、文档锁定内容宽 1680 并居中，页边距保持 24 |
| 1366–1920 | 默认展开 240，推挤内容 |
| 1281–1365 | 默认折叠 64；展开时覆盖在内容上，不占位 |
| ≤ 1280 | 锁定折叠。页面最小宽度 1280，更窄时横向滚动 |

可用内容宽度 < 1300 时改为紧凑密度：多列改为更少列，表格收起次要列，间距收紧一档。字号不变。

内容区顶栏高 56，内部控件高 36。静止时透明，内容距顶 24；滚动后变为毛玻璃（表面色约 62% 不透明度，模糊 24），底边一条分割线。一级页面左侧是页面名。二级及以下是面包屑，最多完整显示三级，更长时收成「第一级 … 倒数第二级 当前」。步骤流在顶栏右侧放步骤，主操作贴在滚动区底部。其他页面的搜索、筛选放在顶栏右侧。

弹窗位于最上层，遮罩模糊，以缩放淡入出现。宽度按 24 列计：小 6 列、中 9 列、大 14 列。圆角 16。

## 控件外观

按钮文字和图标保持单行，图标不被压缩。按下时缩放到 0.97。禁用时改为表面-3 底、弱文字，并去掉阴影。

| 变体 | 外观 | 用途 |
|---|---|---|
| 主按钮 | 强调色底，白字。悬停变亮并加光晕，按下再深一档 | 当前屏幕的主动作，仅一个 |
| 次按钮 | 表面-3 底。悬停再抬一档 | 辅助动作 |
| 描边 | 透明底，1px 控件线。悬停铺表面-2 | 筛选、次级动作 |
| 幽灵 | 无底，次文字。悬停变主文字并铺表面-2 | 工具栏、低优先级 |
| 危险 | 危险色底，白字。悬停加危险色光晕 | 删除等不可逆操作 |

尺寸：小 32×水平 12（字 12，圆角 4）；中 40×水平 16（字 13，圆角 8）；大 48×水平 24（字 14，圆角 8）。字重 600。

输入框为填充式，底用表面-2，圆角 8。聚焦时强调色描边加 4px 强调色柔光。错误时改为危险色描边，并在下方给出危险色说明。

图标只取 16、20、24、32、40、48、64。线宽随尺寸变化，颜色继承当前文字色。默认线性；只有字形有足够大的封闭轮廓时才用面性。

图表只使用图表色板的六色。K 线涨为危险色、跌为成功色。

## 反馈外观

同一时刻的反馈按下面的位置和时长出现，不要另做一套样式。

| 种类 | 外观 |
|---|---|
| 提示 | 顶部居中，距顶 24，条目间距 8。约 2.4 秒后消失。同时最多 3 条。自上淡入 |
| 通知 | 右上角，边距 24，宽 360，条目间距 12。约 4.5 秒后消失，指针悬停时暂停。同时最多 4 条。自右滑入 |
| 确认 | 常驻，直到用户选择。危险操作的确认按钮用危险色 |
| 活动卡 | 宽 320，浮在右下角 |

语义色：成功用成功色，信息用强调色，警告用警告色，错误用危险色，进行中用强调色并旋转。

## 完成前检查

- [ ] 颜色都能在 tokens.md 的角色表里找到，深浅两套一致
- [ ] 卡片和面板没有外框描边，层级靠表面色阶、间距、圆角和阴影
- [ ] 字号、字重、字距来自字阶；数字用数字字体
- [ ] 间距是 4px 网格上的值；表单项间距 12
- [ ] 圆角与对象匹配；阴影只用规定层级
- [ ] 渐变没有用在会员、主推、Hero 以外的装饰上
- [ ] 布局是 24 列、槽宽 16、导航 240/64，并符合视口分档
- [ ] 每屏一个主按钮；危险色只用于破坏或错误
- [ ] 按钮文字和图标单行；界面没有 emoji
- [ ] 动效时长和曲线来自动效表；减少动效时不再播放
