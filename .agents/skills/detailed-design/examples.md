## 各章范例要点

### §1 需求描述

- **1.1** 量化目标示例：「将发现爆款 → 启动复刻压缩至 ≤ 3 步、≤ 1 分钟」
- **1.7** 差异决策示例：PRD 默认品类 vs UX 默认品类 → 明确「跟 PRD」
- blockquote 规范示例：按钮文案、时间筛选等与 UX 对齐的细则

### §2 流程图

- **2.1** 用户路径含登录判断、筛选刷新、预览/快捷操作分支
- **2.2** sequence 含 loop、alt（成功/失败重试）
- **2.3** stateDiagram 描述实体生命周期（待下载 → 可预览 → 已过期）
- **2.4** 异常表 5~8 行，覆盖第三方失败、未登录、资源未就绪

### §3 功能拆分

- **3.1** 目录树精确到文件名（如 `ViralVideoSyncTask`）
- **3.3** 核心模块（M-005、M-008）用表格展开：平台模板 vs 用户副本、复用 `AliOssUtil`
- **3.4** 任务带依赖链 T-001 → T-002 → T-003

### §4 数据库设计

- ER 图 + 中文对照表 + 关系说明 + 字段明细四层结构
- 4.2 每表含索引说明；4.3 枚举含「是否出现在列表」等业务列
- 4.5 schema 草稿含分隔注释块与 COMMENT ON 示例

### §5 接口设计

- API-004 类复杂接口：响应 JSON + **后端逻辑 5 步** + 拆解任务分支表
- syncStatus 枚举与前端横幅文案一一对应
- 5.4 列出 `@Scheduled`、内部 Service、第三方 Client

### §6 附录

- 术语表区分 PRD「做同款」与 UX「复刻」
- OQ-003 已决项示例：「快速复制仍扣影豆」
