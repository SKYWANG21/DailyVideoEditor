## 4. 功能需求矩阵 (Functional Requirements)
> 注：所有需求必须具备可验证性，且附带唯一 ID 方便追踪。验收标准使用 Given/When/Then 格式，只描述用户可感知的行为和结果，不描述技术实现。需求间有依赖关系时必须在"前置依赖"列标注。

### 4.1 核心功能模块 A (例如：用户认证系统)

| FR-ID | 功能 | 优先级 | 前置依赖 |
| :--- | :--- | :--- | :--- |
| FR-001 | 登录与注册 | P0 | 无 |
| FR-002 | 暗黑模式支持 | P1 | 无 |

- **[FR-001] 登录与注册**
  - **描述:** 用户通过手机号+验证码快速登录。
  - **验收标准 (Acceptance Criteria):**
    1. **格式校验:** Given 用户在登录页已输入手机号, When 输入不符合手机号规则的字符并失焦, Then 输入框变红，下方显示"请输入正确的手机号"。
    2. **验证码防重复:** Given 用户已点击"获取验证码", When 60 秒倒计时未结束, Then 按钮保持灰色不可点击状态。
    3. **残留状态记忆:** Given 用户在登录页已输入手机号但中途退出, When 3 分钟内重新进入登录页, Then 手机号输入框保留之前输入的内容。

- **[FR-002] 暗黑模式支持 (Dark Mode)**
  - **描述:** 页面需根据系统配置或用户手动切换高对比度暗黑皮肤。
  - **验收标准:**
    1. **跟随系统:** Given 用户系统设置为暗黑模式, When 用户首次访问页面, Then 页面自动以暗黑模式渲染。
    2. **手动切换:** Given 用户在页面上, When 点击暗黑模式切换按钮, Then 页面即时切换到对应皮肤，无明显闪烁。
    3. **可读性:** Given 页面处于暗黑模式, When 渲染任何页面元素, Then 文字与背景对比度 ≥ 4.5:1。

### 4.2 核心功能模块 B (例如：批处理与搜索)

| FR-ID | 功能 | 优先级 | 前置依赖 |
| :--- | :--- | :--- | :--- |
| FR-003 | 批量 URL 抓取与内容解析 | P0 | FR-001（需登录态） |

- **[FR-003] 批量 URL 抓取与内容解析**
  - **描述:** 允许用户输入多个 URL，后台并发处理并展示抓取状态。
  - **验收标准:**
    1. **输入:** Given 用户进入批量抓取页, When 在多行文本框中输入以逗号或换行分隔的 URL 列表, Then 系统解析为独立 URL 条目。
    2. **状态流转:** Given 一批 URL 已提交, When 系统处理每个 URL, Then 列表实时展示状态：排队中 → 抓取中 → 成功/失败。
    3. **超时熔断:** Given 某个 URL 已进入抓取中状态, When 15 秒内未收到响应, Then 状态自动置为失败，显示具体错误码。

## 6. 非功能性需求 (Non-Functional Requirements)
> 注：仅描述质量属性指标和约束原则，不涉及具体技术方案选型。

- **性能体验 (Performance):** 页面首屏加载时间 (FCP) 小于 1.5 秒；列表分页查询响应时间小于 500ms。
- **交互反馈 (UX):** 所有异步操作（提交/删除/导入）需有 loading 态，不可重复点击；删除操作需二次确认；失败操作需给出明确的错误提示文案。
- **数据隐私 (Security):** 涉及用户敏感信息必须加密存储，不得在控制台明文打印；文件上传需校验文件类型白名单。

## 7. 数据埋点与可度量指标 (Data Tracking & Metrics)

> 注：定义关键业务事件及埋点字段，确保每个业务目标都有对应的度量手段。埋点描述聚焦于"什么用户行为需要被记录"和"记录哪些业务字段"，不涉及 SDK 选型或技术实现。

| 事件 ID | 事件名称 | 触发时机 | 关键字段 | 对应 KPI |
| :--- | :--- | :--- | :--- | :--- |
| EVT-001 | 用户登录成功 | 用户完成手机号验证码登录 | user_id, login_type | 日活用户数 (DAU) |
| EVT-002 | 批量抓取提交 | 用户点击"开始抓取"按钮 | user_id, url_count, batch_id | 功能使用率、单次抓取 URL 数 |
| EVT-003 | 抓取任务完成 | 单个 URL 抓取成功或失败 | batch_id, url, status (success/failed), duration_ms | 抓取成功率、平均响应时间 |

### 埋点与业务目标映射

| 业务目标（来自第 2 节） | 度量指标 | 关联埋点事件 | 目标值 |
| :--- | :--- | :--- | :--- |
| 提升用户活跃度 | DAU | EVT-001 | 日均 ≥ 1000 |
| 提升抓取效率 | 平均单次抓取 URL 数 | EVT-002 | ≥ 15 |
| 保障服务质量 | 抓取成功率 | EVT-003 | ≥ 98% |
